```cpp
int l = 0;   // 窗口左边界
int sum = 0; // 窗口需要维护的变量; 
for (int i = 0; i < n; i++) { // 枚举窗口右边界i，当前窗口[l, i]

  nums[l]离开窗口，维护相关变量  // 往往需要写循环，来不断缩小窗口 while () { 缩小窗口; 维护窗口变量; }
  
  满足条件时，更新答案

```





# 定长滑动窗口



常见问题

* 固定长为k的窗口，求窗口内满足某条件的元素最多/最少/最大等问题
* 固定长为k的窗口，求窗口外满足某条件的元素最多/最少/最大等问题 -> 正难则反：可以转化为窗口内问题





# 不定长滑动窗口

不定长滑动窗口主要分为三类：求最长子数组，求最短子数组，求子数组个数。

注：滑动窗口相当于在维护一个队列。右指针的右移可以视作入队，左指针的右移可以视作出队，二者往同一个方向移动

## 越短越合法 -> 求最长/最大

* 求满足某条件的最长/最大 -> 需要求出以i结尾的最长/最大

右指针i入队，使得窗口变大，越大越不合法 -> 缩小窗口，左指针l出队，使得窗口变小 -> 越短越合法，使得窗口重新满足条件 -> 刚好满足条件时，即为以i结尾时的最长xxx，用于更新答案 -> 随着i不断右移，不断更新答案

## 越长越合法 -> 求最短/最小

* 求满足某条件的最短/最小 -> 需要求出以i结尾的最短/最小

写法1：右指针i入队，使得窗口变大，越大越合法 -> 尝试缩小窗口: while(l出队后，窗口满足条件)（如果左指针l出队后，变小的窗口仍满足条件，说明找到了更短的，那么l就出队）-> l不断出队，如果l再出队，窗口就会不满足条件，那么退出循环 -> 此时窗口即为以i结尾时的最短xxx，用于更新答案 -> 随着i不断右移，不断更新答案

写法2：前者是在while循环外更新答案，也可以在while循环内更新答案

右指针i入队，使得窗口变大，越大越合法 -> while(当前窗口满足条件) { 更新答案; 缩小窗口; } -> 那么随着while循环，窗口不断缩小，不断更新答案 -> while出循环时，以i结尾时的最短xxx已经更新过答案了 -> 随着i不断右移，不断更新答案

## 求子数组个数

### 越长越合法

题目通常求：至少满足某条件的数目

一般统计数目时要写 ans += left。

内循环通常写法：while(满足题目条件) { 缩小窗口; } 

内层循环结束后，[left,right] 这个子数组是不满足题目要求的，但在退出循环之前的最后一轮循环，[left−1,right] 是满足题目要求的。由于子数组越长，越能满足题目要求，所以除了 [left−1,right]，还有 [left−2,right],[left−3,right],…,[0,right] 都是满足要求的。也就是说，当右端点固定在 right 时，左端点在 0,1,2,…,left−1 的所有子数组都是满足要求的，这一共有 left 个。

我们关注的是 left−1 的合法性，而不是 left。

### 越短越合法

题目通常求：至多满足某条件的数目

一般统计数目时要写：ans += right - left + 1。

内循环通常写法：while (当前窗口不满足条件) { 缩小窗口; }

内层循环结束后，[left,right] 这个子数组是满足题目要求的。由于子数组越短，越能满足题目要求，所以除了 [left,right]，还有 [left+1,right],[left+2,right],…,[right,right] 都是满足要求的。也就是说，当右端点固定在 right 时，左端点在 left,left+1,left+2,…,right 的所有子数组都是满足要求的，这一共有 right−left+1 个。

### 恰好型滑动窗口

例如，要计算有多少个元素和恰好等于 k 的子数组，可以把问题变成：

* 计算有多少个元素和 ≥k 的子数组。
* 计算有多少个元素和 >k，也就是 ≥k+1 的子数组。

答案就是元素和 ≥k 的子数组个数，减去元素和 ≥k+1 的子数组个数。这里把 > 转换成 ≥，从而可以把滑窗逻辑封装成一个函数 solve，然后用 solve(k)−solve(k+1) 计算，无需编写两份滑窗代码。

总结：「恰好」可以拆分成两个「至少」，也就是两个「越长越合法」的滑窗问题。

注：也可以把问题变成 ≤k 减去 ≤k−1，即两个「至多」。可根据题目选择合适的变形方式。

注：也可以把两个滑动窗口合并起来，维护同一个右端点 right 和两个左端点 left1 和 left2，我把这种写法叫做三指针滑动窗口。
